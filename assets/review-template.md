# 审查记录骨架（不随交付物发布）

> **放哪里**：`<用户指定目录>/_review/<起>-<止>-审查记录.md`（页码用书内页，例：`478-479-审查记录.md`）。目录同样受铁律 5 约束。
> **门禁怎么跑**（把审查记录指给门禁，交付物本身不含这两节）：
>
> ```bash
> python scripts/check_report.py --md "<交付物>.md" --pages <起>-<止> --outdir "<用户指定目录>" --review "<本文件>"
> # 学习版再加 --mode study
> ```
>
> **为什么不放进交付物**：这两节是"过程凭据"，读者不需要。留在交付物里只会让报告越读越像工作日志。
> **那怎么让用户看到**：**阶段任务完成时**在收尾说明（`SKILL.md` 的固定字段清单）里汇报——第一轮审查的 ❌/💡/✅ 计数、第二轮待确认项逐条（或"待确认：无"）。用户要原始记录时再把本文件给他。
