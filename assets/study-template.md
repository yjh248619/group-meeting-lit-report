# 学习版固定骨架（复制后填充）

> **用法**：先按铁律 5 确认输出目录，再把下面整段复制到 `<用户指定目录>/<起>-<止>-学习.md`，把 `<>` 占位符替换为实际内容。文件名固定为「页码-页码-学习」，例：书 p.478–479 → `478-479-学习.md`（**不加文献简称、不加下划线**）。
> **交付物里不放「首轮自检与修订记录」与「待确认项」**：这两节写进同目录 `_review/<起>-<止>-审查记录.md`（骨架见 `assets/review-template.md`），门禁用 `--review` 指向它。阶段任务完成时在收尾说明里汇报这两项。
> **不要改标题层级与编号格式**：`scripts/check_report.py --mode study` 按这套结构做机器校验。
> **这是与「组会汇报版」并列的第二套骨架，不是它的分支**：组会版逐句（`#### 句 N`），学习版按段（`#### 第 N 段`）。两者各自独立，不许混写。
> **本页没交代的符号与公式，必须交代来源 + 补足推导**（防幻觉规则 I）：用到目标页范围之外定义的字母参数或公式时，写清它首次定义在哪一页／哪一公式；由公式推出的数值（如"饱和值 = β₁ + β₂"）**必须写出推导的关键一步**，不许只给结论；自己算出来的数不许写成原文印出的数。
> 章节序号规则：`## 二、…` 下面只能出现 `2.1 / 2.2 / 2.3 …`，从 1 连续；每一页重新从 1 起；附录用 `### 附 1 / 附 2 …`。
> 段落编号规则：`#### 第 N 段` 在**每一页内从 1 连续**，不得跳号或重号。
> 小节不适用时**保留标题**并写明"本页无图""本页无公式"，否则编号会断。

## 机器校验对照表（`--mode study`）

| 规则 | 级别 | 校验点 | 对应位置 |
|---|---|---|---|
| R1 | 阻断 | 页码对账存在 | `## 〇` 里的 `页码对账：PDF <a> = 书 <X>` 或对照表 |
| S2 | 阻断 | 段落编号连续、每段有原文与译文 | `#### 第 N 段` + `- **原文**：` + `- **译文**：` |
| R3 | 阻断 | 小节编号与章节序号一致且连续 | `### 2.1 / 2.2 / 2.3`、`### 附 1 / 附 2` |
| R4 | 阻断 | 无占位符残留 | 全文（`TODO`/`{{`/`XX页`/`待填`） |
| R5 | 阻断 | 有自检与修订记录章节 | 交付物**或** `--review` 指向的审查记录文件里的 `## 首轮自检与修订记录` |
| R6 | 阻断 | `--gate phase2` 时无未关闭待确认项 | 同上，审查记录文件里的 `## 待确认项` |
| S7 | 警告 | 图表讲解覆盖十条 | `### n.m 图 X.Y 精简讲解` 里的 回答什么问题/为什么要有这张图/怎么读/坐标轴/点/线段/符号/颜色/图例/这张图还能说明什么 |
| S8 | 警告 | 公式给出前后文联系 | `### n.m 公式与重点符号的前后文联系` |
| R8 | 警告 | 数值表标注出处 | 表格所在小节的 `【按图读数】…反算…` |
| R9 | 警告 | 英文直引带页码或公式号 | 引文行及其后 2 行 |
| R10 | 警告 | 推断类表述带 `【推论】` | 相应句子 |
| R11 | 警告 | 页码引用未大幅越界 | 全文 `p.N` / `第 N 页` |
| R12 | 警告 | 存在「待确认项」小节 | 交付物**或**审查记录文件里的 `## 待确认项` |
| R13 | 阻断 | 报告落在用户指定的输出目录内 | 跑门禁时带 `--outdir "<用户确认的目录>"`（铁律 5） |
| R14 | 警告 | 「希腊字母参数 ≈/＝ 数值」必须就近有出处 | 该行或上下 1 行内要有 `p.N` / `式 (X.Y)` / `图 X.Y` / `表 X.Y` / `【原文】` / `【推论】` / `【按图读数】`（防幻觉规则 I，**默认开启**） |

> **S7 是弱校验**：它靠关键词判断"哪类元素没被解释"，报出来的是**疑点**而不是判决。图例确实不存在、颜色确实不承载含义时，只要正文把这件事写明，关键词就命中，不会报警。真正的判据仍是人读一遍：**图上出现过的每一类元素，正文都要有一句解释它代表什么统计量。**
