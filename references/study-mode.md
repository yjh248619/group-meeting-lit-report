# 学习版（课题组学习解析版）执行细则

**什么时候走这条线**：用户要的是"能自己看懂"，不是"能上台讲"。典型说法是"课题组学习""学习解析版""按段翻译""便于看懂版""我自己先读懂这几页"。

**与组会汇报版的分工（两条线，不许混）**：

| 维度 | 组会汇报版 | 学习版 |
|---|---|---|
| 翻译粒度 | 逐句英中对照，`#### 句 N` | **按段**，`#### 第 N 段` |
| 图表讲解 | 必讲清单 10 条 | **精简**：不写延伸项，但元素逐类讲清 |
| 公式／重点 | 术语逐条解释 + 组会预设问答 | **前后文联系**解释 |
| 服务目标 | 扛住组会上被追问 | 让读者尽可能容易看懂 |
| 骨架 | `assets/report-template.md` | `assets/study-template.md` |
| 交付命名 | `<起>-<止>-汇报.md` | `<起>-<止>-学习.md` |

用户**同时要两版**时，产出两个文件，不要试图合成一份。

**两份骨架共用同一套锚点**（`## 〇、阅读说明与页码对账`、`## 一、章节地图`、`## 二、第 X 页`、`### n.m`、`## 首轮自检与修订记录`、`## 待确认项`、`### 附 N`），差别只在 `2.2` 一节：组会版是 `#### 句 N`，学习版是 `#### 第 N 段`。

## 一、三个操作定义（写的时候按这个判，不要凭感觉）

### 1. 「精简」的边界

**必写**：这张图回答什么问题；**为什么要有这张图**；怎么读（可操作的判读顺序）；**每一类元素各一句解释**；**这张图还能说明什么**。

**不写**：组会预设问答、易错点、读图局限、与其他图的接口、精确读数表（用户明确要才写）。

判据不是"写满 10 条"，而是"**元素齐 + 读法在**"。少写延伸项不算缺陷，漏掉一类元素才算。

### 2. 「元素一定要解释清楚」的判据

**图上出现过的每一类元素，正文都必须有一句说明它代表什么统计量。** 元素按下面六类逐类过：

| 类别 | 要交代什么 |
|---|---|
| 坐标轴 | 轴标签、刻度值、线性还是对数、量纲、覆盖范围、分类轴还是连续轴 |
| 点 | 点代表什么（点估计？观测？）；没有点就写明"本图无散点" |
| 线段 | 实线／虚线／误差条／区间线／曲线各代表什么；线宽差异是否承载含义 |
| 符号 | 圆／叉／实心／空心各代表什么；不用符号就写明 |
| 颜色 | 颜色是否承载统计含义；不承载就写明"颜色不承载统计含义" |
| 图例 | 图例在哪、怎么读；无图例就写明"含义靠图注给出" |

**不合格判据（写死）**：某类元素出现了，而文中没有解释它代表什么统计量 → 不合格。

"没有出现"也要写成一句话（"本图无散点""图内无图例"），因为**不写出来，读者分不清是"没有"还是"你没讲"**。

### 3. 「前后文联系」的判据

每个重点符号或公式回答五件事，缺一不可：

1. **首次定义在哪**——本文献哪一页／哪一公式，标页码；
2. **本页为什么用它**——本页哪个结论依赖它；
3. **后文还会用在哪**——被谁引用、用来说明什么，标页码；
4. **各符号含义与量纲**——逐个符号交代含义、量纲、取值范围；
5. **由它推出的结论与推导**——依据这条式子 → 关键一步（取极限／代入／整理）→ 结果。**不许只给结论**（防幻觉规则 I）。

第 5 条是"看得懂"和"只能照抄"的分界线。典型例子：由图 19.5 的纵轴读出"零浓度处 ≈ 14.7、平台 ≈ 114"，就要写清**为什么平台 = β₁ + β₂ 而不是 β₂ 单独**——`x → ∞` 时 `(x/β₃)^(−β₄) → 0`，分式趋于 1，故 `g → β₁ + β₂`【推论】。

**同时要把数的来源贴对标签**：β̂₁、β̂₂ 是**书 p.475 印出的后验估计**（`β̂₂ = 99.7 [96.8, 102.9]`）→ `【原文 p.475】`；平台 `β₁ + β₂ = 114.4` 是**算出来的**【推论】。**别写反**——`β₂ = 114 − 14.7` 是因果颠倒（114 由 β₁+β₂ 得出，不是从图上读出来的），这种"看起来严谨"的错法比不写推导更危险。

沿用既有机制：本页引用但实体在别页的进附录；作者说"后文讨论"的必须翻到后文追回并标页码（见 `references/anti-hallucination.md` 规则 G）。

## 二、按段翻译的写法

- **一段一对**，`#### 第 N 段` + `- **原文**：` + `- **译文**：`。编号**在每一页内从 1 连续**，不得跳号或重号。
- 分段以**原文自然段**为准，不按句号切、不合并两段。
- 图注、表注、公式说明**单独成块**并保留其"注"的性质；它们不占段号，放在对应的图表小节里。
- 原文排印错误照译并加注说明（例：括号不配对）。
- 专有名词首现给"中文（English，缩写）"三件套；同一术语全篇译名一致。
- 译文**不增不删**：不加原文没有的因果与评价（`references/anti-hallucination.md` 规则 D）。

按段翻译比逐句更容易"顺手改顺"，所以写完一段要回查一次：这句译文里的因果、程度、限定词，原文有没有？

## 三、图表精简讲解的写法

标题固定为 `### <n>.<m> 图 <编号> 精简讲解`（表同理）。正文按**十条**走：回答什么问题 / 为什么要有这张图 / 怎么读 / 坐标轴 / 点 / 线段 / 符号 / 颜色 / 图例 / 这张图还能说明什么。

- **第 2 条「为什么要有这张图」**：作者为什么在正文这个位置放它、它替读者省掉了什么、支撑了正文哪一句断言。**只描述画面不算讲图**——这条答不出来，说明图还没读懂。
- **第 10 条「这张图还能说明什么」**：超出作者本页明说的可读信息（形态、量级、组间差异、与相邻页的呼应…）。凡超出原文的一律标 `【推论】` 或 `【按图读数】` 并写明依据；确实没有更多可说，就写"除上述外本图未提供额外信息"，不要硬编。

顺序本身就是读图顺序：**先说什么问题、为什么有它，再说怎么读，然后逐类交代元素，最后说它还能说明什么**。元素条目要短，一句话说清"是什么统计量"即可，不要展开成组会版那样的判读清单。

## 四、门禁怎么跑

```bash
python scripts/check_report.py --md <学习版>.md --pages <起>-<止> --mode study \
    --outdir "<用户确认的输出目录>" --review "<用户指定目录>/_review/<起>-<止>-审查记录.md"
python scripts/check_report.py --md <学习版>.md --gate phase2 --mode study   # 进入阶段二前，参数同上
```

- `--mode` 不写默认是 `report`，会按逐句骨架去查，学习版必然报 S2/R2 不符。**学习版一定要显式写 `--mode study`**。
- 结构类（R1 / S2 / R3 / R4 / R5 / R6）报出即 `exit 1`，**不得宣称阶段一完成**。
- 内容类（S7 / S8 / R8–R12）只警告；S7、S8 是**弱校验**，报出来的是疑点，按上面的操作定义人工复核后决定改不改，并在收尾清单里说明处置。
- 收尾清单、豁免开关、五条铁律、三档标注与组会版完全一致，见 `SKILL.md`。**输出目录同样必须先确认（铁律 5）**：学习版的 MD、`figures/`、`evidence/` 与阶段二产物都落在用户指定的目录里。

## 五、证据纪律

`references/anti-hallucination.md` 的 A–H **对学习版同样全部适用**，两条最要紧：

- **A 先读后引**：没实际读过的页码／正文不许引用，也不许写"书中还提到…"。
- **B 结论必须与所引原文逐字对上**：原文说 `no major problems` 就不能写成"拟合完美"。

不确定的一律写 `<待确认:…>`，禁止把猜测写成确定值。学习版的读者是"第一次读这篇文献的人"，**一处臆测会被当成事实记住**，所以这条比组会版更严。
