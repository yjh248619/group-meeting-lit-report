# 报告固定骨架（复制后填充）

> **用法**：先按铁律 5 确认输出目录，再把下面整段复制到 `<用户指定目录>/<起>-<止>-汇报.md`，把 `<>` 占位符替换为实际内容。文件名固定为「页码-页码-汇报」，例：书 p.478–479 → `478-479-汇报.md`（**不加文献简称、不加下划线**）。
> **不要改标题层级与编号格式**：`scripts/check_report.py` 会按这套结构做机器校验（编号连续、每句有原文与译文、图表要素、页码对账）。
> **交付物里不放「首轮自检与修订记录」与「待确认项」**：这两节写进同目录 `_review/<起>-<止>-审查记录.md`（骨架见 `assets/review-template.md`），门禁用 `--review` 指向它。阶段任务完成时在收尾说明里汇报这两项。
> 章节序号规则：`## 二、…` 下面只能出现 `2.1 / 2.2 / 2.3 …`，从 1 连续；附录用 `### 附 1 / 附 2 …`。

## 机器校验对照表

`scripts/check_report.py` 会核对下列内容。写成上面那套骨架即可全部满足：

| 规则 | 级别 | 校验点 | 对应位置 |
|---|---|---|---|
| R1 | 阻断 | 页码对账存在 | `## 〇` 里的 `页码对账：PDF <a> = 书 <X>` 或对照表 |
| R2 | 阻断 | 句子编号连续、每句有原文与译文 | `#### 句 N` + `- **原文**：` + `- **译文**：` |
| R3 | 阻断 | 小节编号与章节序号一致且连续 | `### 2.1 / 2.2 / 2.3`、`### 附 1 / 附 2` |
| R4 | 阻断 | 无占位符残留 | 全文（`TODO`/`{{`/`XX页`/`待填`） |
| R5 | 阻断 | 有自检与修订记录章节 | 交付物**或** `--review` 指向的审查记录文件里的 `## 首轮自检与修订记录` |
| R6 | 阻断 | `--gate phase2` 时无未关闭待确认项 | 同上，审查记录文件里的 `## 待确认项` |
| R7 | 警告 | 图表详解覆盖要素 | `### n.m 图 X.Y 详解` 里的 回答什么问题/横坐标/纵坐标/怎么读；带 `--figures-full` 时再查 为什么要有这张图/这张图还能说明什么 |
| R8 | 警告 | 数值表标注出处 | 表格所在小节的 `【按图读数】…反算…` |
| R9 | 警告 | 英文直引带页码或公式号 | 引文行及其后 2 行 |
| R10 | 警告 | 推断类表述带 `【推论】` | 相应句子 |
| R11 | 警告 | 页码引用未大幅越界 | 全文 `p.N` / `第 N 页` |
| R12 | 警告 | 存在「待确认项」小节 | 交付物**或**审查记录文件里的 `## 待确认项` |
| R13 | 阻断 | 报告落在用户指定的输出目录内 | 跑门禁时带 `--outdir "<用户确认的目录>"`（铁律 5） |
