## Step 1　接收与确认输入

必须问清（缺一项就停下来问，不要猜）：

1. **输出目录**（**铁律 5，写入前必须确认**）：报告、`figures/`、`evidence/`、`_review/` 这次放在哪个文件夹。用户没指定、或说"随便／你定"时，**报出建议目录并停下等一句确认**——不许默认写当前工作目录，也不许拿上次会话的目录顶替
2. **文献路径**（若是图书，还要问清"用户说的是 PDF 页码还是书内印刷页码"，并算出偏移）
3. **页码范围**（明确是 PDF 页还是书页）
4. **输出模式**：默认组会汇报版（逐句英中对照）；用户说「课题组学习」「学习解析版」「按段翻译」「便于看懂版」时改走学习版（按段），细则见 `references/study-mode.md`。两版都要就产两个文件
5. **听众背景**（是否同方向、是否需要解释基础概念）
6. （可选）**时长与形式**：口头讲 / 交文档 / 要做 PPT

**四项齐了才开工**：文献路径、页码范围、输出模式、输出目录。前四项任缺一项都不要开始取证。

第一部分先做**页码对账**：渲染该页 → 从页眉页脚读出印刷页码 → 建立偏移，并把这个对账表写进报告开头（例：`PDF 491 = 书 476`）。**这一步不能省，它是全篇引用页码可信的前提。**

## Step 2　取证

严格按 `references/pdf-evidence-extraction.md` 执行。要点：

- 取**正文文字**（`get_text("text")`）并**修正连字符断行**（`metabo-\nlized` → `metabolized`）
- 取**上下文章节地图**：本页前后的所有小节标题与页码，`§x.y` 从哪到哪
- **图表必须单独渲染成高清 PNG 并逐张人工判读**；坐标轴刻度标签常常不在文本层，必须靠渲染图定位
- **能反算的读数一律反算**（`get_drawings()` 取矢量端点 + 轴刻度位置映射），不许只用目测
- 记录**图/表/公式/缩写在本页是否首次出现**，以及"本页引用但实体在别页"的情况

### 证据纪律（贯穿 Step 2–3）

- **先读后引**：引用任何原句、页码、公式号、读数之前，必须已经实际读到过对应页/段。没读到的**不许引用**，也不许写"书中还提到…"。取证范围要在报告开头写明（例：`取证范围：PDF 491–492 全文；另回溯 486–498 用于章节地图`）。
- 完整规则见 `references/anti-hallucination.md`（A–H），写每一节之前先过一遍。

### 生成前自检（动手写之前先数清，防漏译）

在开始写任何一个页面章节之前，**先数清并记录**（写进 `_review/pass1_checklist.md` 顶部）：

| 要数的东西 | 依据 | 用途 |
|---|---|---|
| 本页有几张图 / 几张表 / 几条公式 | 正文与图注实际出现的编号 | 写完逐项核对，防漏 |
| 本页正文有几个段落、图注/表注分别几条 | 分段统计 | 逐句翻译的完整性核对 |
| 各有多少句 | 按句号/分号切分 | 句子编号连续性的核对 |
| 本页引用但实体在别页的项 | 正文里出现的"见图 x""式 (x.x)" | 附录必须覆盖 |

**写完一页后必须回头逐项打勾**；数量对不上就说明漏了，必须补。

## Step 3　撰写报告

### 固定的文档骨架

**直接复制 `assets/report-template.md`**，不要自己另起结构。那份骨架与门禁脚本的判定点一一对应（编号规则、句子对格式、图表要素、页码对账），改了结构就会导致 `check_report.py` 报错。

**走学习版时改复制 `assets/study-template.md`**——骨架不同（`#### 第 N 段` 而非 `#### 句 N`），不要把它当成汇报版的变体去改。学习版的门禁要显式加 `--mode study`。

骨架要点（详细写法见模板文件）：

```
# 标题：<文献> 第 X–Y 页 逐句翻译与图表讲解
## 〇、阅读说明与页码对账（对账表 + 三档标注说明 + 术语约定）
## 一、章节地图（本页在整章/整节中的位置，前后小节与页码）
## 二、第 X 页
    ### 2.1 本页版式与功能
    ### 2.2 逐句翻译（#### 句 N + **原文** / **译文**）
    ### 2.3 图 X.Y 详解（必须含：回答什么问题 / 为什么要有这张图 / 横坐标 / 纵坐标 / 怎么读 / 这张图还能说明什么）
    ### 2.4 符号与公式的来源交代（符号来源表 + 推导）
    ### 2.5 组会预设问答
## 三、第 Y 页（同上的子结构，编号 3.1、3.2…）
## 附录
    ### 附 1 / 附 2 … 本页用到的前文接口（公式要给公式号 + 首次定义页码 + 用它推出了什么）
```

**交付物里没有「首轮自检与修订记录」与「待确认项」**：这两节写进 `_review/<起>-<止>-审查记录.md`，门禁带 `--review` 指向它。骨架见 `assets/review-template.md`。

**编号规则（会被脚本硬检查）**：`## 二、…` 下只能出现 `2.1 / 2.2 / 2.3 …` 且从 1 连续；每一页重新从 1 起；附录用 `### 附 1 / 附 2 …` 连续。

### 逐句翻译的写法

- **英中对照**，一句一对，编号连续（编号仅用于组会指认，与原文段落切分保持一致）。
- 图注、表注、公式说明**单独成块**并保留其"注"的性质。
- **原文排印错误照译并加脚注说明**（例如括号不配对）。这会让听众知道你读得细。
- 专有名词首现给"中文（English，缩写）"三件套。
- 译文里不要顺手补原文没有的因果与评价。

### 图表解释的"必讲清单"（每张图必须逐条覆盖，缺一条算未完成）

1. **这张图回答什么问题**（一句话）
2. **为什么要有这张图**：作者为什么在正文这个位置放它——它替读者省掉了什么、支撑了正文哪一句断言。答不出这一条，说明这张图还没读懂，只是在描述画面
3. **横坐标**：轴标签 / 刻度值 / 线性还是对数 / 量纲 / 覆盖范围 / 分类轴还是连续轴
4. **纵坐标**：同上
5. **每个图形元素的统计含义**：点、线段、误差条、带、符号（圆/叉/实心/空心）、颜色分别代表什么
6. **精确读数**：能反算的全部列出（表格式），并标注"由矢量坐标反算/目测"
7. **怎么读才有结论**：给出可操作的判读清单（"什么样的形态叫有问题"），而不是只说"看起来没问题"
8. **本图的结论**：引用原文措辞（如"no major problems appear"），不要升级为"拟合完美"
9. **读图局限**：坐标轴选择造成的视觉失真、刻度标注不全、折线结点数少等
10. **与其它图/正文的接口**：这张图的数据来自哪、结果又去了哪
11. **这张图还能说明什么**：超出作者本页明说的可读信息（形态、量级、组间差异、与相邻页的呼应…）。**凡超出原文的一律标 `【推论】` 或 `【按图读数】` 并写明依据**；确实没有更多可说时，就写"除上述外本图未提供额外信息"，不要硬编
12. **易错点**：至少列 2 条"听众最可能读错的地方"

> **只描述画面不算讲图**：第 2 条与第 11 条是"读懂了"和"抄了一遍图注"的分界线。带 `--figures-full` 跑门禁时，R7 会按第 1、2、3、4、7、11 条逐项核对（第 5、6、8、9、10、12 条靠人读）。

### 跨页符号与公式的来源交代（防幻觉规则 I，两条必做）

**触发**：正文用到了**目标页范围内没有给出定义或解释**的字母参数、公式，或由它们推出的数值。这类内容最容易出两种毛病——**来源不明**（读者不知道这个符号是谁、哪来的）和**推导跳步**（只给结论，读者不能验证）。

**必做一：标注来源**（四选一，必须落在纸面上）

| 情况 | 怎么写 |
|---|---|
| 前文定义过 | `（首次定义见书 p.474，式 (19.1)）`——**页码与公式号/图号/表号都要给** |
| 从图/表读出 | 标 `【按图读数】`，写清从哪个坐标轴、哪个刻度反算 |
| 由本文献模型推出 | 标 `【推论】`，写出依据是哪条式子/哪条假设 |
| 本文献通篇未定义 | `<待确认:该符号在本文献中未给出定义>`，登记 `state/oq-ledger.md` |

**必做二：补足推导**（不许只给结论）

凡"由公式推出某个结果"的地方，正文里要写全三段：**依据（哪条式子）→ 关键一步（取极限／代入／整理）→ 结果**。

> **标准例子**（BDA3 书 p.476 图 19.5 的横轴范围）：模型 `E(y|x,β) = β₁ + β₂/(1+(x/β₃)^(−β₄))` 定义在书 p.474 的式 (19.1)，**本页没有重复写出**。要说明"横轴到 100 已接近饱和区"，正确写法是：
>
> - `x → 0` 时 `(x/β₃)^(−β₄) → +∞`，故 `E → β₁`——β₁ 是零浓度处的基线【推论】；
> - `x → ∞` 时 `(x/β₃)^(−β₄) → 0`，故 `E → β₁ + β₂`——**饱和值 = β₁ + β₂，不是 β₂ 单独**【推论】；
> - 由图读得 β₁ ≈ 14.7、β₁+β₂ ≈ 114【按图读数】，故 **β₂ = 114 − 14.7 ≈ 99.7**【推论】。
>
> **错误写法**：`饱和处是 β₁ + β₂ ≈ 14.7 + 99.7 ≈ 114`——两处都没交代（β₂ 哪来的？为什么相加？），读者只能照抄。

**落地位置**：汇报版的 `### n.m 符号与公式的来源交代`、学习版的 `### n.m 公式与重点符号的前后文联系`、以及附录的「本页用到的前文接口：公式」。

### 数值一致性纪律

- 同一量在报告不同位置出现时**必须完全一致**（这是第一轮审查最容易抓到的问题）。
- 凡"从图上读出的数"，必须做**二次校验**。三种可用手段：
  - **矢量反算**：`get_drawings()` 的坐标 + 轴刻度映射（首选）
  - **与原文给出的数字交叉验证**：若正文另给出了区间/均值，用它的数字反推轴映射是否自洽
  - **结构验证**：R/ggplot 的默认轴规则（如 4% 边距、1-2-5 对数刻度、隔一标注）是否与矩形边界吻合
- 只有通过二次校验的数字才能写进报告；没通过的，写"目测约"，并在待确认项里登记。
- **提交前做一次全篇数值扫描**：把同一量在不同位置的取值列出来逐个比对，不一致的以证据更强的一处为准，并同步修正其它位置（这是第一轮审查 E 类最常见的失分点）。

### 质量回退上限（不要反复硬试）

图表坐标反算**最多尝试 2 次**（换映射假设 / 换刻度定位方式）。两次仍不能自洽时：

1. 停止反算，改用**目测读数**，并在报告里标成 `【按图读数（目测）】`，同时在数值表下方写明"该值由目测得到，未经矢量反算校验"；
2. 把"该图刻度/映射未能确证"作为一条待确认项登记进 `state/oq-ledger.md`；
3. **禁止**继续尝试第 3、4 种假设——反复硬试既浪费时间，也容易在报告里留下自相矛盾的读数。

阶段二编译同理：自动修错重编译最多 5 轮，仍失败就把错误清单原样交给用户，不交半成品。

## Step 4　第一轮审查（内容层）

逐条过下面 5 类，**每条都要在 `_review/pass1_checklist.md` 里留下"查了什么—结果—处置"**，不允许只写"已检查无问题"。

| 类别 | 要查什么 | 典型病灶（真实案例） |
|---|---|---|
| **A 前后逻辑** | 同一结论在不同小节是否自相矛盾；"总结句"是否与前面的分析一致 | 一处说"区间很窄"，另一处说"相对不确定度最大" |
| **B 方法论** | 统计与学科概念是否用错；坐标系与术语的对应关系是否正确 | 把"双对数图上的直线"说成"线性下降"；把 accuracy 当作 precision 的证据；把分类轴当连续轴比较 |
| **C 证据回溯** | 每条数字/结论能否指回页码、图号、公式号；有没有"原文没写但被写成原文说的" | 把反算读数写成"书中给出"；把推断写成引用 |
| **D 解释完整性** | 对照"必讲清单"与下面这张**全局缺漏检查表**逐项过 | 只说了"低于检测限也有估计"，却没解释检测限是按什么定的 |
| **E 数值自检** | 全部数字重算一遍；相对量 vs 绝对量是否混用；区间宽度是加性还是乘性 | 用绝对区间宽度比较精度，得出相反结论 |

### 严重级三档（审查产出必须分级，不要一刀切）

审查结果按下面三档标注，**报告里只列 ❌ 与 💡，✅ 只在统计里计数**：

| 档位 | 含义 | 处置 |
|---|---|---|
| **❌ 阻断** | 事实/数值错误、前后矛盾、方法论错误、无出处的断言 | 必须修正后才能进入下一轮 |
| **💡 建议** | 可以更清楚、更完整，但不影响正确性（如某处可以再补一个数字验证） | 记录，可由用户决定是否处理 |
| **✅ 通过** | 已核对无误 | 只在统计行计数，不逐条列出 |

统计行写法：`本轮第一轮审查：❌ x 处（已修正）、💡 y 处（已处理/待定）、✅ 逐项通过`。

**机器可判定的部分交给脚本**：Step 6 会跑 `check_report.py`，它报出的 R1–R6 结构类问题一律按 ❌ 处理，R7–R12 内容类按 💡 处理。人工审查只需要处理脚本判不了的（逻辑矛盾、方法论、解释完整性）。

### 全局缺漏检查表（D 类的固定清单）

- [ ] 页码对账表是否存在且经核对
- [ ] 章节地图是否完整（本页承接哪些小节、后文兑现了什么承诺）
- [ ] 每个缩写/术语首现处是否已解释，且使用该文献的特定含义
- [ ] 每个公式的**每个符号**是否都解释了（含下标、上标、约束范围）
- [ ] 每张图是否覆盖"必讲清单"10 条
- [ ] **"后文才解释"的内容是否被追回来**（例：某页说"曲线形状后面讨论"，必须翻到后文找到正式解释并补入，并标注页码）
- [ ] 作者**自述的局限**是否被引用（样本量、单一实验、外推范围）
- [ ] 数据规模/实验设计是否交代（几条曲线=几个人？几个孔？几个水平？）
- [ ] 结论边界是否交代（该结论只适用于哪个群体/条件）
- [ ] 是否存在"看起来很懂但其实是猜测"的句子（最常见于"为什么这样做更好"）

## Step 5　第二轮审查（上下文回溯 → 闸门）

这一轮**只做一件事**：回到文献的更大上下文，把阶段一一路上"没弄明白或做了假设"的地方变成一份**待确认项清单**。

回溯动作：

1. 回到**本章/本节**通读一遍目录级结构，确认本页的位置与承接关系无误
2. 找出**本页引用但实体不在本页**的图、表、公式、缩写、前文定义，逐一到附录补齐
3. 找出**后文对本页的兑现**（承诺过的解释、后续的补充数据与限制说明）
4. 找出**术语歧义**：同一词在该文献中的特定含义 vs 一般含义（例：dilution 是"剩余比例"还是"稀释倍数"）
5. 找出**作者但书**：结论适用范围、数据规模、未展示的研究

### 先读台账，再产出清单（关键：不要重复问同一个问题）

在动笔写清单之前，**必须先读 `state/oq-ledger.md`**，对每个"拿不准"的点按下面四种情况分别处理：

| 台账命中情况 | 处置 |
|---|---|
| 命中且 `状态 = resolved` | **直接采用答案**，当场消解，**不再写进待确认项，也不再问用户** |
| 命中且 `状态 = answered` | 采用答案，并在报告里注明"依已于 `<日期>` 确认的口径" |
| 命中且 `状态 = open` | 报告里**引用其 OQ-ID**，不重复登记、不重复提问 |
| 未命中 | 写进待确认项，并**在台账追加一行 `open`**（`OQ-<文献简称>-<页>-<序号>`） |

去重键：术语/概念按 `类型 + 问题`；同一问题只允许一行，新的出处追加到同一行。台账里的 `open` 行**不直接**阻断阶段二，闸门看的是报告 `## 待确认项` 一节是否还有未关闭项——两边必须一一对应。

产出 `_review/pass2_open_items.md`（同时同步进 `_review/` 审查记录里的 `## 待确认项` 与 `state/oq-ledger.md`），每条形如：

```
[待确认 1] 事实：×××  证据：p.xxx 原文/图 x.x 读数
          我的处理：暂按 A 方案写入 §x.y
          为什么需要你确认：×××（会影响结论方向 / 影响图表解读 / 无法从文献内部判定）
          可选方案：(a) … (b) … (c) …
```

### 闸门规则（硬约束）

- 清单**为空** → 在第一轮审查结论上加一句"第二轮审查无待确认项"，方可进入阶段二。
- 清单**非空** → **立即停止**，用交互式提问逐条向用户确认（一次问不超过 4 条，重要的先问）。
  - 用户确认后：**先修正正文，再重跑第一轮审查中受影响的条目**（A/B/C/D/E 里凡与被改内容相关的都要重查），然后再看清单是否归零。
  - **禁止**自行闭合待确认项；**禁止**在清单未归零时进入阶段二；**禁止**把待确认项直接写进成品 MD 当"脚注"了事（除非用户明确要求保留为开放问题）。
- 归零后，把修订明细写成 `_review/` 审查记录里的「首轮自检与修订记录」附表（问题 / 性质 / 核查依据与处置），并在文档生成说明里写明版本号（v1、v2…）。**不要写进交付物**。

## Step 6　交付

1. **先跑门禁脚本**（不可跳过）：

   ```bash
   python scripts/check_report.py --md <报告>.md --pages <起>-<止> \
       --outdir "<用户确认的输出目录>" --review "<用户指定目录>/_review/<起>-<止>-审查记录.md" \

   ```

   - 报出 **R1–R6 结构类问题（带 `[x]`）** → `exit 1` → **不得宣称阶段一完成**，修完重跑。
   - 报出 **R7–R12 内容类问题（带 `[!]`）** → 不阻断，但必须在收尾清单的「第一轮审查」一行里说明处理情况（改了什么 / 为什么不改）。
